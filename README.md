# Delta Travel 2.0

Website đặt tour du lịch và nghỉ dưỡng cao cấp tại Việt Nam.

## Giới thiệu
Delta Travel cung cấp các gói tour du lịch chất lượng cao khám phá các điểm đến hàng đầu: Hạ Long, Đà Nẵng, Phú Quốc, Sa Pa, Đà Lạt, Miền Tây,... với giao diện hiện đại, tối ưu trải nghiệm người dùng và quy trình đặt tour nhanh chóng.

## Tính năng nổi bật
- Giao diện hiện đại, responsive mượt mà trên mọi thiết bị.
- Tìm kiếm và lọc tour thông minh theo điểm đến, ngân sách, ngày khởi hành.
- Xem chi tiết lịch trình tour, các dịch vụ bao gồm.
- Đặt tour và thanh toán nhanh chóng (hỗ trợ chuyển khoản QR).
- Đánh giá từ khách hàng và cẩm nang du lịch hữu ích.

## Công nghệ sử dụng
- **HTML5 & CSS3** (Custom UI, Flexbox, CSS Grid)
- **Bootstrap 5 & Bootstrap Icons**
- **Vanilla JavaScript** (ES6+)

## Hướng dẫn chạy thử nghiệm
Chỉ cần mở file `index.html` trực tiếp trên trình duyệt hoặc sử dụng Live Server (VS Code).
